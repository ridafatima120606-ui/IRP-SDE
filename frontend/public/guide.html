🔌 Backend API Endpoints

All APIs are available at http://localhost:5000/api/v1

🍽️ Menu API
GET /menu/items
GET /menu/items/:id
📅 Reservations API
POST /reservations
GET /reservations/:id
PUT /reservations/:id
⏱️ Waitlist API
POST /waitlist/join
GET /waitlist/status/:id
PUT /waitlist/:id/cancel
💰 Pricing API
GET /pricing/menu
GET /pricing/item/:id
GET /pricing/forecast
💳 Orders API
POST /orders
GET /orders/:id
PUT /orders/:id/status
🎁 Loyalty API
GET /loyalty/points/:userId
POST /loyalty/redeem
GET /loyalty/rewards
